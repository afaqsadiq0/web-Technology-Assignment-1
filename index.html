Academic Purpose & Scope

This website is an academic project developed for CSC336 Web Technologies to demonstrate front-end development concepts using HTML5 and CSS3.

Engineered with clean semantic markup, custom CSS variables, Flexbox header/footer patterns, and a robust CSS Grid system, this platform showcases responsive design principles across mobile, tablet, and desktop viewports without reliance on third-party frameworks.
