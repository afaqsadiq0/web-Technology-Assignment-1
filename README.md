## 📌 Project Overview

This repository contains a high-quality, responsive educational web portal developed for the **CSC336 Web Technologies** course. The project is built entirely using semantic **HTML5**, modern **CSS3** (utilizing custom properties, Flexbox, and CSS Grid), and lightweight **Vanilla JavaScript** without reliance on external CSS frameworks like Bootstrap or Tailwind.

## 📚 Curriculum Modules & Lecture Details

### 1. Lecture 01: Web Development Overview
- **Topics Covered:** Internet vs. Web, Client-Server model, Web Platforms (LAMP, MERN, Cloud), Core Terminologies (Client, Server, HTTP/HTTPS, URL, DNS, IP), International Standards (W3C, WHATWG, ECMA, IETF), Technical Constraints, Application Categories (Static, Dynamic, SPA, PWA, CMS), and Modern Development Environments (IDEs, DevTools, Git).
- **Features:** Technical definition table, platform overview cards, and developer workflow terminal code snippet.

### 2. Lecture 02: Tiered Web Architecture
- **Topics Covered:** Logical Layers vs. Physical Tiers, One-Tier Architecture (Monolithic local host), Two-Tier Architecture (Client-Server, Thick vs. Thin client), and N-Tier / Three-Tier Architecture (Presentation, Application/Business Logic, Data Storage).
- **Features:** Pure HTML/CSS rendered architecture topology diagrams, security isolation analysis, and a comprehensive comparative matrix across scalability, security, and maintenance.

### 3. Lecture 03: HTML & HTML5 Fundamentals
- **Topics Covered:** Evolution of HTML to HTML5, standard document boilerplate anatomy (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`), heading hierarchy (`<h1>`–`<h6>`), running prose paragraphs, hyperlinks (`<a>` with security attributes), responsive images (`<img>` with accessible `alt` text), and ordered/unordered lists.
- **Features:** Syntax-highlighted code panels with one-click copy buttons and a live rendered vector diagram demonstrating the client-server request/response cycle.

### 4. Lecture 04: Block, Inline & Semantic HTML
- **Topics Covered:** Block-level elements vs. inline elements, CSS dimension and margin box behavior, semantic HTML5 landmark tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`, `<figure>`), and the benefits of semantic structure for screen-reader accessibility (a11y) and SEO.
- **Features:** Exhaustive Block vs. Inline comparison table and a live CSS visual wireframe illustrating modern semantic document architecture.

### 5. Lecture 05: HTML Forms
- **Topics Covered:** `<form>` container attributes (`action`, `method="GET|POST"`, `enctype`), accessible `<label>` associations via `for` and `id`, text fields, email validation, password masking, radio buttons (mutually exclusive grouping), checkboxes (multi-select), `<select>` dropdowns, multi-line `<textarea>`, and submit/reset buttons.
- **Features:** A live, styled interactive student course enrollment form with real-time submission confirmation.

### 6. Lecture 06: CSS Fundamentals
- **Topics Covered:** Cascading Style Sheets role, rule anatomy (selectors, declaration blocks, properties, values), implementation methods (Inline, Internal `<style>`, and External `<link>`), selector categories (type, class, ID, grouping, descendant, universal), cascade specificity calculation (inline > ID > class > element), and the browser rendering pipeline (DOM + CSSOM &rarr; Render Tree &rarr; Layout &rarr; Paint).
- **Features:** Syntax anatomy code blocks and an HTML/CSS diagram explaining the browser render tree synthesis.

### 7. Lecture 07: CSS Box Model & Positioning
- **Topics Covered:** Concentric Box Model layers (Content, Padding, Border, Margin), dimension calculation differences between legacy `content-box` and modern `border-box` sizing, and CSS positioning schemes (`static`, `relative`, `absolute`, `fixed`, and `sticky`).
- **Features:** An attractive, layered CSS Box Model visualizer with color-coded boundaries and an absolute child coordinate demonstration.

### 8. Lecture 08: CSS3, Flexbox & Grid
- **Topics Covered:** Modular CSS3 enhancements (CSS custom properties, `box-shadow`, `border-radius`, `linear-gradient`, transitions), one-dimensional Flexbox (container vs. item properties, main axis, cross axis), two-dimensional CSS Grid (column/row tracks, `fr` fractional units, `grid-template-columns`), an architectural comparison matrix (Flexbox vs. Grid), and mobile-first responsive media queries (`@media`).
- **Features:** Interactive live playgrounds demonstrating Flexbox spacing distribution and a responsive multi-column CSS Grid.

### 9. Special Laboratory Module: CSS Grid Garden (All 28 Levels Completed)
- **Topics Covered:** Gamified W3C CSS Grid mastery across all 28 levels: `grid-column-start`, `grid-column-end`, negative index coordinates (`-1`), relative track stretching via `span`, shorthand properties (`grid-column`, `grid-row`, `grid-area`), source-order manipulation with `order`, flexible fractional sizing (`fr`), `repeat()`, `grid-template-columns`, `grid-template-rows`, and master `grid-template`.
- **Features:** 
  - **100% Visual Proof:** Exactly 28 full-resolution verified screenshots (`level-01.png` to `level-28.png`).
  - **Interactive 28-Level Explorer:** Dynamic category filtering, fast pill switcher, syntax-highlighted solutions, and one-click copy.
  - **In-Browser Live Garden Simulator:** 5x5 responsive CSS grid board with real-time DOM garden rendering.
  - **28-Level Proof Catalog Matrix:** Visual card gallery with responsive lightbox zoom.
  - **Doubt & Viva Station:** Common interview questions and custom query logging.
  - **Knowledge Check Quiz:** Selectable MCQs with live scoring.

## 🎨 Design System & Technical Highlights

1. **Design System & Typography:**
   - Curated color scheme utilizing deep slate navy (`#0f172a`), royal sapphire primary accents (`#2563eb`), emerald success indicators (`#10b981`), and subtle border treatments (`#e2e8f0`).
   - Clean academic typography powered by Google Fonts: **Inter** for headings/body prose and **JetBrains Mono** for code blocks.
   - Global CSS variables declared in `:root` for colors, shadows, border-radii, and transitions.

2. **CSS Layout Paradigms:**
   - **Flexbox:** Used for the sticky navigation header, student badge pills, hero button groups, and lecture pagination footers.
   - **CSS Grid:** Used for the 4-card Course Overview section, 8-card Lecture Catalog, and semantic document structures.

3. **Responsive Viewports:**
   - Fully responsive across mobile (320px, 375px), tablet (768px), and desktop (1024px, 1440px) viewports.
   - Fluid auto-fitting grids and media queries prevent horizontal overflow or broken layouts.
   - Accessible animated hamburger toggle for mobile devices.

4. **Lightweight Usability Enhancements:**
   - One-click "Copy" functionality on code blocks with visual feedback.
   - Smooth "Back to Top" scrolling button.
   - Pure CSS architecture diagrams and interactive box model visualizer.

## 🚀 How to Run Locally

You can run this project locally using any of the following standard methods:

### Method 1: Direct File Execution (Zero Configuration)
Simply navigate into the project directory and double-click either:
- `index.html` (root redirect gateway) OR
- `web-technologies/index.html` (direct homepage)

It will open immediately in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Method 2: Python Local Server
If Python is installed on your system, open your terminal/PowerShell in this directory and execute:
```bash
python -m http.server 8080
```
Then navigate to: `http://localhost:8080` in your browser.

### Method 3: Visual Studio Code Live Server
1. Open this workspace folder in Visual Studio Code.
2. Right-click on `web-technologies/index.html`.
3. Select **"Open with Live Server"**.
