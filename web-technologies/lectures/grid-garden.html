CSS Grid Garden: All 28 Levels Walkthrough & Interactive Lab

A complete, gamified laboratory module for mastering CSS Grid layouts. Features full visual proof of completion across all 28 levels, syntax-validated solutions, technical taxonomy, in-browser simulator, and viva knowledge check.

🎯 Learning Objectives & Practical Outcomes

  • ✓ Master grid line coordinates using grid-column-start and grid-column-end (Levels 1–5).
  • ✓ Employ relative track spanning with the span keyword and negative indexing (Levels 6–9).
  • ✓ Harness shorthands: grid-column, grid-row, and the 4-value grid-area master shorthand (Levels 10–17).
  • ✓ Manipulate visual source ordering via the order property without modifying HTML DOM hierarchy (Levels 18–19).
  • ✓ Architect responsive track templates using fractional fr units, repeat(), and grid-template (Levels 20–28).

# 1. Pedagogical Taxonomy of the 28 Grid Garden Levels

Grid Garden by Codepip is a gamified interactive learning platform specifically engineered to teach the W3C CSS Grid Layout specification. Through 28 incremental challenges, students learn how to water carrots and eliminate weeds by positioning water blocks and defining custom garden grids.

🌱 Part I: Grid Lines & Spanning (L1–L9)

Introduces vertical grid lines (1 to 6), negative boundary indices (-1 to -6), and the flexible span [n] syntax for relative item stretching.

📐 Part II: 2D Coordinates & Shorthands (L10–L17)

Consolidates separate start/end rules into grid-column: start / end, adds vertical grid-row, and combines them into grid-area: row-start / col-start / row-end / col-end.

🔄 Part III: Order Manipulation (L18–L19)

Overrides source-code document order using order: [integer], enabling dynamic item rearrangement without DOM manipulation.

⚡ Part IV: Template Tracks & Master Sizing (L20–L28)

Transitions to container properties: defining column and row tracks with grid-template-columns, repeat(), fr fractional units, and master grid-template.

🔄 Solution: span Keyword Mechanics
When you pass a raw number like grid-column-start: 3;, it targets the 3rd vertical line from the left edge. However, when preceded by the span keyword (grid-column-start: span 3;), it acts as a relative width declaration, instructing the element to span across 3 consecutive tracks relative to its terminating anchor line.
📐 Solution: grid-area Coordinate Sequence
The grid-area 4-value shorthand follows the exact clockwise-adjacent pattern: grid-row-start / grid-column-start / grid-row-end / grid-column-end. In Level 16, grid-area: 1 / 2 / 4 / 6; places the item starting at row 1 and column 2, ending at row 4 and column 6.
🔄 Solution: Visual Reordering via order
By default, all grid items possess an initial order: 0. Setting order: -1 assigns a priority lower than 0, causing the browser layout engine to paint that item ahead of all default siblings along the auto-placement flow without altering the source HTML.
⚡ Solution: Level 28 Master Shorthand
The master grid-template syntax is [rows] / [columns]. In Level 28, 1fr 50px / 20% 1fr specifies two rows (first row consumes all flexible free space, second row is exactly 50px) and two columns (first column is 20% width, second column consumes all remaining space with 1fr).
