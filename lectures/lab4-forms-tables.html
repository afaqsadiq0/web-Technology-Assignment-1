Lab 04 Viva Q&A & Academic Technical Notes

Key academic concepts for COMSATS viva examinations on HTML Tables, Forms, and external CSS styling.

Theory & Viva

Q1: Why were <table> tags historically used for layout, and why is this practice discouraged in modern web engineering?

Answer: In the late 1990s before CSS support was standardized across browsers, tables provided the only reliable multi-column layout mechanism. However, using tables for layout violates HTML5 semantic standards: screen readers announce tables as data matrices to visually impaired users, page load performance suffers from deep nesting, and table columns cannot fluidly reflow or reorder for mobile screens without CSS overrides. Modern web engineering uses CSS Flexbox and CSS Grid instead.

Q2: What is the benefit of External CSS compared to Inline or Internal CSS?

Answer: External CSS separates content (HTML structure) from presentation (styling). It enables browser caching of the stylesheet file, resulting in faster repeat visits across multi-page portals, facilitates team collaboration, enforces consistent design tokens across hundreds of pages, and maintains single-point maintenance when theme updates are required.

Q3: What makes the "Repeat Password" validation on forms essential for user experience?

Answer: Since password input fields mask characters with bullets or asterisks (type="password") to prevent shoulder surfing, users cannot visually verify typographical errors. The confirmation field ensures that accidental keystrokes are caught immediately before account creation locks out the user.

Q1 Which HTML attribute is used to make a table cell span horizontally across multiple columns?
Explanation: Correct! The colspan attribute defines how many table columns a single <td> or <th> element spans across.
Q2 To link an external stylesheet named style.css to an HTML document, which element is placed inside the <head>?
Explanation: Correct! The <link rel="stylesheet" href="..."> tag links external CSS resources to the HTML document.
